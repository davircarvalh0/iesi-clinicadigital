# US-01 — Criar ou vincular paciente mestre

O Cadastro consome `consulta.agendada` v1 pela fila `cadastro.consultas` (RabbitMQ) e usa apenas seu PostgreSQL. O CPF chega com ou sem pontuação e é persistido com 11 dígitos. A chave única arbitra criações simultâneas, preserva o ID do primeiro registro e impede que dados de uma consulta sobrescrevam o cadastro mestre.

Em uma transação, o Cadastro registra o `id_evento` recebido, insere o paciente se ele ainda não existir e grava `paciente.atualizado` v1 na outbox com a mesma correlação da consulta. Uma consulta distinta recebe confirmação de vínculo mesmo para paciente existente; a repetição do mesmo evento não produz nova saída. O consumidor confirma a mensagem após o commit. Em caso de falha, a transação reverte todas as escritas e a mensagem pode ser reprocessada.

| Critério | Evidência reproduzível |
| --- | --- |
| CA1 | Teste de banco: CPF novo e com máscara, ID estável, contato preservado e vínculo na outbox. |
| CA2 | Teste de banco: seis eventos distintos e seis reentregas concorrentes para o mesmo CPF. Teste Compose: duplicata reenviada com o serviço parado e ignorada depois que ele volta. |
| CA3 | Teste de banco: falha induzida na outbox reverte paciente e marcador; reenvio após remover a falha funciona. |

Execute em um Compose dedicado, com dados fictícios e `CANAL_ENVIO=log`. Exemplos para PowerShell e portas padrão:

```powershell
$env:COMPOSE_PROJECT_NAME = 'iesi-clinicadigital-us01-teste'
$env:CANAL_ENVIO = 'log'
docker compose up -d --build --wait
# Aguarde http://localhost:3003/saude responder antes de executar os testes.
$env:DATABASE_URL = 'postgresql://cadastro:cadastro@localhost:5435/cadastro'
$env:TEST_US01_DB = '1'
npm run test:us01:db -w @clinica/cadastro
$env:TEST_US01_REINICIO = '1'
npm run test:us01:reinicio
```

Para portas alternativas, ajuste `DATABASE_URL`, `TEST_CADASTRO_URL` e `TEST_RABBITMQ_URL`. O teste de reinício usa a configuração Compose do ambiente (inclusive `COMPOSE_FILE`, se definido) e para brevemente o serviço Cadastro daquele projeto.
