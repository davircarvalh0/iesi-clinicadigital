# US-02 — Consultar e manter o cadastro mestre

As rotas abaixo são do Cadastro. Na Recepção, passam pelo proxy existente, com o prefixo `/api/cadastro`.

| Método e rota | Contrato |
| --- | --- |
| `GET /pacientes` | `busca` por nome ou CPF (até 120 caracteres), `pagina` (1–100000, padrão 1), `tamanhoPagina` (1–100, padrão 20). Retorna `pacientes`, `total`, `totalFiltrado`, `pagina` e `tamanhoPagina`. Cada item tem `id`, `cpf`, `nome`, `telefone`, `email` e `revisao`. A tela aplica a máscara de apresentação ao CPF. |
| `POST /pacientes/busca-cpf` | Recebe `{ "cpf": "000.123.456-78" }` ou 11 dígitos. Retorna `200 { paciente: { id, cpf, nome, telefone } }` ou `200 { paciente: null }`. Nenhum registro é criado. |
| `GET /pacientes/:id` | Retorna os campos da listagem mais `nascimento` (data `AAAA-MM-DD` ou `null`) e `convenio` (texto ou `null`). Paciente inexistente: `404`. |
| `PATCH /pacientes/:id` | Exige a revisão atual e pelo menos um campo. Atualiza apenas os dados enviados: telefone com DDD, e-mail, nascimento (data válida e não futura) e convênio (até 120 caracteres). `null` limpa e-mail, nascimento ou convênio. Retorna o detalhe atualizado. |

O CPF é imutável. Se enviado no PATCH, funciona como conferência: o CPF do próprio paciente é aceito, um CPF de outro paciente retorna `409` e um CPF diferente ainda não cadastrado retorna `400`. Revisão antiga também retorna `409`, com mensagem específica. Erros retornam `{ erro: string }` sem dados internos. Respostas de pacientes usam `Cache-Control: no-store`.

Alterações mantêm a publicação de `paciente.atualizado` v1 na outbox transacional. Nascimento e convênio ficam apenas no Cadastro.

## Verificação

Use o ambiente de teste isolado de [US-01](US-01.md), com as migrações aplicadas:

```powershell
$env:TEST_US02_DB = '1'
npm run test:us02:api -w @clinica/cadastro
```

O teste cobre busca equivalente/ausente (CA1), persistência e remoção dos dados, CPF duplicado e revisão antiga (CA2), paginação, campos mínimos e erros sanitizados (CA3). Para verificar a apresentação, abra **Pacientes**, confira a máscara no CPF e use **Editar cadastro**. Salve nascimento e convênio e abra novamente para conferir a persistência.
