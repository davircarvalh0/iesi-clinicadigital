# US-29 · Dashboard administrativo (indicadores)

Etapa 5 do fechamento do MVP. **Critérios inferidos**; precisam do aceite do PO.

| Critério | Descrição | Situação |
| --- | --- | --- |
| CA1 | `GET /indicadores/resumo`: pacientes cadastrados, consultas por situação e taxas de comparecimento, falta e cancelamento no período. | Pronto |
| CA2 | `GET /indicadores/consultas`: contagem por dia (dia da clínica) e por profissional. | Pronto |
| CA3 | Só o administrador acessa; período padrão é o mês corrente; período inválido ou maior que 366 dias é recusado. | Pronto |

## Decisões

- Os indicadores ficam no Agendamento, sem chamada síncrona a outro serviço.
- `pacientesCadastrados` conta CPFs distintos das consultas. No protótipo todo paciente do mestre nasce de uma
  consulta (US-01), então o número coincide. **Se o Cadastro ganhar cadastro avulso de paciente, isso precisa mudar.**
- Só a API; a tela do dashboard não faz parte desta entrega.

Evidência: `npm run test:us29`.
